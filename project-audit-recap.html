1. Executive Summary

Artist.Dev is a personal creative portfolio for a frontend developer and UI designer. It uses a monochrome editorial visual language with anime-inspired artwork, file/window metaphors, hard borders, offset shadows, monospace metadata, and motion effects.

The project is an early-stage static portfolio prototype. The main browsing structure exists, but the production build is currently blocked by a missing image import. Project imagery, social links, demos, source links, and contact submission are incomplete.

5. UI and Design System

  • Palette: near-black, off-white, light gray, gray borders, with green online status and a defined red destructive token.
  • Typography: CSS declares Inter, Space Grotesk, and JetBrains Mono, while the layout loads Geist and Geist Mono. This is inconsistent.
  • Layout: Tailwind containers, six-unit horizontal padding, desktop grids, responsive stacking at md/lg breakpoints.
  • Shapes: mostly square controls, thin black borders, offset black shadows, small rounded window-control dots.
  • Effects: dotted background, backdrop blur, grayscale image effects, hover transforms, Framer Motion entrances.
  • Identity: monochrome editorial portfolio with software-window and artist-studio references.

The visual direction is intentional and strongest on Home, Works, and the shared WindowFrame component. It becomes less complete around functional controls and missing assets.

6. Components and Dependencies

Active components

  • Navigation: fixed header with pathname-based active state; desktop-only links.
  • WindowFrame: shared file/window presentation wrapper used across the main pages.
  • Toaster and Radix toast primitives: used by the clipboard confirmation.
  • TooltipProvider: mounted globally, but no tooltip usage was found.

Maintenance findings

  • A duplicate WindowFrame exists under src/components/components/WindowFrame.tsx and appears unused.
  • Many Radix packages are declared but have no direct source imports: accordion, alert dialog, aspect ratio, avatar, checkbox, dialog, dropdown menu, label, popover, select, separator, and slot.
  • Starter SVG assets and a placeholder HTML project asset appear unused.

7. Assets and Build Evidence

  • One real image exists: public/assets/image/cover-web.png, a monochrome anime-style character illustration used on Home.
  • The About page imports the absent app/assets/images/oc-character.png.
  • All six project image paths in lib/data.ts point to absent /projects/*.jpg files.
  • public/oc/ and app/assets/images/ are empty.

10. Recommended Roadmap

  2. Add valid project images or update the project records to valid assets.
  3. Fix TypeScript and ESLint errors.
